## TL;DR

形参（parameter）是函数声明中定义的变量，而实参（argument）是调用函数时传入的实际值。例如，在函数 `function add(a, b) { return a + b; }` 中，`a` 和 `b` 是形参。调用 `add(2, 3)` 时，`2` 和 `3` 是实参。

---

## 形参和实参的区别

### 形参

形参是函数定义中列出的变量。它们是占位符，在调用函数时会接收传入的值。

示例：

```js
function greet(name) {
  console.log('Hello, ' + name);
}
```

在此示例中，`name` 是一个形参。

### 实参

实参是调用函数时传入的实际值。这些值会赋给函数定义中对应的形参。

示例：

```js live
function greet(name) {
  console.log('Hello, ' + name);
}
greet('Alice'); // Output: "Hello, Alice"
```

在此示例中，`"Alice"` 是一个实参。

### 主要区别

- 形参是函数签名的一部分，而实参是提供给函数的实际值。
- 形参用于定义函数，而实参用于调用函数。

### 结合两者的例子

```js live
function add(a, b) {
  // a 和 b 是形参
  return a + b;
}

const result = add(2, 3); // 2 和 3 是实参
console.log(result); // Output: 5
```
